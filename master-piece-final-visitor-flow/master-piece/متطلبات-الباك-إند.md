# نطاق الربط بعد اعتماد الفرونت

- ASP.NET Core MVC وIdentity للتسجيل وتأكيد البريد والجلسات والأدوار واسترداد الحساب.
- ملفات المستخدمين ومهارات التعلم والتعليم الاختيارية، والتصنيفات والمهارات ومستوى المهارة وفئة الوصول وحالة النشر.
- Free/Plus مع فرض وصول Advanced وتبادلها وحجز الخبراء من السيرفر، والتحقق من الدفع ورصيد الجلسات.
- طلبات التبادل/التطوع وقبولها والمحادثات واللقاءات والتقييمات، مع تفويض بيانات المشاركين.
- طلبات اعتماد الخبراء والمراجعة البشرية، وتقدم المسار المتسلسل المرتبط بسجلات تعلم حقيقية.
- التوصيات إرشادية فقط، ضمن دليل المهارات المتاح. لا تمنح AI صلاحية اشتراك أو ترقية أو إنجاز.
- لا نبني ميزات إشعارات أو بلاغات حسابات أو صندوق دعم أو إعدادات نظام أو أدوار موظفين متعددة أو مسودات محتوى أو صفحة سجل تدقيق ضمن النطاق الحالي المحذوف. يبقى التحقق الأمني الأساسي والصلاحيات والتحقق من المدخلات على السيرفر ضروريًا.
- نراجع Schema والعلاقات والقيود والفهارس والبيانات الأساسية أولًا، ثم ننفذ SQL Server. لم يُنشأ سكربت SQL في هذه النسخة.
