# رحلة المستخدم في النسخة المبسطة

الزائر: الصفحة الرئيسية ← استكشاف التصنيفات والخطط ← إنشاء حساب وتأكيد البريد ← إكمال الملف ← الترحيب.

المستخدم دون مسار: استكشاف مهارة ← شريك من المجتمع أو خبير ← طلب وتنسيق ← محادثة ولقاء ← تقييم. Basic وتبادلها مجانية، وAdvanced تحتاج بلس، وحجز الخبير يحتاج بلس حتى لمهارة Basic. إنشاء المسار اختياري.

المستخدم مع مسار: Set Career Path ← الهدف والمستوى والوقت والمهارات المعروفة ← فتح Timeline مباشرة. إنجاز كل خطوة يفتح التالية. الوصول لخطوة Advanced يحتاج بلس لبدء تعلمها وتبادلها. زر محاكاة الإنجاز لتجربة الواجهة فقط.

التوصيات: AI.html يقدم ترتيب مهارات وأسبابًا وإرشادًا حسب مدخلات المستخدم باستخدام قواعد ثابتة حاليًا. لا يوجد اتصال بخدمة AI، ولا قرار تلقائي باشتراك أو ترقية أو حجز. الإدارة لا تحتاج صفحة Suggested skill orders في هذه النسخة.

الأدمن: إدارة الأعضاء والتصنيفات والمهارات وفئة الوصول Basic/Advanced وطلبات الخبراء والتقييمات والخطط والاشتراكات والمعاملات والإحصاءات. بروفايله منفصل، والمحادثات واللقاءات ليست متاحة له. أُلغيت ميزات البلاغات والإشعارات وصندوق الدعم والأدوات الإضافية المطلوبة.

قبل الداتا بيز نراجع الواجهة أولًا. بعد اعتمادها نحدد الجداول والعلاقات والقيود والبيانات الأساسية ثم نكتب سكربت SQL Server. صفحات التجربة وروابطها لا تمنح صلاحيات حقيقية.


تحديث: آخر زر بإنشاء المسار يفتح التايم لاين الأصلي مباشرة. كبسة الداشبورد View My Career Path تفتح نفس الصفحة. حذفت إعدادات المستخدم؛ تعديل البروفايل من نافذة داخله.
