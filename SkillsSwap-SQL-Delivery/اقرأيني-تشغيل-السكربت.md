# تشغيل وتسليم قاعدة Skills Swap

1. افتحي SQL Server Management Studio واتصلي بالسيرفر.
2. افتحي SkillsSwap_Final.sql بواسطة Ctrl+O.
3. اضغطي F5 لتنفيذ الملف كاملًا دون تحديد جزء منه.
4. السكربت ينشئ قاعدة مستقلة اسمها SkillsSwap_Final، ولا يغير SkillsSwap_Trial أو SkillsSwapDB أو قواعد أخرى.
5. أول تشغيل ينشئ 36 جدولًا و69 مفتاحًا خارجيًا و188 سجلًا مرجعيًا وتجريبيًا. يتضمن قيود CHECK وUnique وفهارس ومفاتيح مركبة.
6. يتضمن فحصًا تلقائيًا قبل Commit: الجداول والعلاقات والقيود وتطابق بيانات اللقاءات والتقييمات والمحادثات والمسار والرصيد. إذا فشل الفحص، تتراجع عملية الإنشاء داخل القاعدة الجديدة ولا تُعتمد البيانات.
7. رسالة النجاح لأول تشغيل: SkillsSwap_Final created successfully. Database checks passed.
8. إعادة تشغيل نفس الملف لا تكرر البيانات ولا تمسح تعديلاتك. لعرض التفاصيل افتحي 02_Verify_SkillsSwap_Final.sql وشغليه؛ بعد تعديل بياناتك قد تختلف الأعداد عن عينات البداية بشكل طبيعي.

## نطاق التحقق

الصورة التي أرسلتِها من SQL Server أثبتت نجاح إنشاء بنية النسخة التجريبية ووجود36 جدولًا و69علاقة و188سجلًا. ملف التسليم يحفظ نفس تعريفات الجداول وبيانات تلك النسخة، ويضيف الإعدادات القياسية والفحص الذاتي ويستخدم اسم قاعدة جديدًا. فحص القيود الأخير لقاعدة التجربة موجود في03_Quick_Check_Existing_Trial.sql؛ عدد المخالفات يجب أن يكون صفرًا.

لم نتصل ببوابة دفع أو خدمة AI أو Zoom، ولم ننفذ باك إند MVC بعد. الأسعار والحجوزات والمدفوعات داخل العينات وهمية. كود MVC لاحقًا يفرض جلسة الدخول وصلاحية المستخدم والتحقق من Plus وتعارض المواعيد والعمليات الذرية؛ وجود الجداول لا يساوي تنفيذ تلك الخدمات.

## ربط Visual Studio لاحقًا

المفاتيح Guid للحسابات: ApplicationUser : IdentityUser<Guid> وApplicationRole : IdentityRole<Guid>. يجب أن تطابق EF configuration أسماء الجداول والأعمدة والمفاتيح المركبة والأطوال وRowVersion. لا تشغلي Migration أولية تنشئ نفس الجداول فوق هذه القاعدة بلا baseline؛ لم نضع __EFMigrationsHistory وهميًا.

المشروع المعتمد: master-piece-final-visitor-flow.zip. لا جداول إشعارات أو بلاغات حسابات أو Settings أو كورسات أو أدوات أدمن محذوفة. LearningSessionChanges لتغيير اللقاء بين طرفيه، وPaymentProviderEvents لتكامل الدفع، وليس لإعادة ميزات البلاغات أو Audit log.
